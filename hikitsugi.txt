## ✅ 1. 支払い（その１）

### フロント

`?page=payment`

フォーム入力：

* カテゴリー
* 日付（デフォルト当日）
* 金額
* 支払者（なつ / たか）
* 誰用（なつ / たか / 共有）
* 備考

### バックエンド処理

### 家計簿処理

* 月シート名形式：`2026年2月`
* 月シートがなければ自動生成
* 見出し行自動作成：

  ```
  購入品 | 日付 | 金額 | カテゴリー | 経費 | 備考
  ```
* H1 = 月の初め
* H2 = 残高
* I2 = =I1 - SUM(C2:C)
* データは必ず2行目から開始（C列基準で制御）

### 精算処理

シートが無ければ自動生成：

* A1 = なつ→たかの貸し
* B1 = 合計
* B2 = =ROUND(SUM(A2:A),0)

A2から追記されるよう修正済み。

精算ロジック：

| payer | forWhom | delta |
| ----- | ------- | ----- |
| なつ    | たか      | +1    |
| たか    | なつ      | -1    |
| なつ    | 共有      | +0.5  |
| たか    | 共有      | -0.5  |
| 自分用   |         | 0     |

## ✅ 2. 使用食材（その２：途中段階）

### 実装済み

`?page=use`

* 日付入力
* 所有者選択（なつ / たか）
* 食材一覧を取得してプルダウン表示

### API

```javascript
action: "food.list"
```

### food.list の処理

* 食材管理シート（なつ or たか）
* 見出し行1行目
* 空行除外
* 返却データ：

```
{
  name,
  item_id,
  amountPerUnit,
  remain,
  unit
}
```

プルダウン表示は：

```
具材名 (残:◯単位)
```
