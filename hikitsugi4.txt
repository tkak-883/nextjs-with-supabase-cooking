# 📘 食材精算アプリ 引き継ぎ資料（Supabase移行版）

---

# 1️⃣ プロジェクト概要

## 目的

2人（なつ・たか）の

* 食材管理
* 使用金額計算
* 支払い記録
* 月次精算

をLINEミニアプリ想定UIで管理する。

---

## 技術構成

| 項目   | 技術                      |
| ---- | ----------------------- |
| フロント | Next.js 16 (App Router) |
| UI   | Tailwind + shadcn       |
| DB   | Supabase (PostgreSQL)   |
| API  | Next.js Route Handlers  |
| デプロイ | Vercel                  |
| 認証   | 現在なし（Admin Client使用）    |
